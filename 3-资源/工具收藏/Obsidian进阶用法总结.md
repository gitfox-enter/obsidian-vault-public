# Obsidian 进阶用法总结

> 核心方法：PARA + GTD + 知识卡片

## 笔记体系（PARA）

| 目录 | 用途 |
|------|------|
| 0-收件箱 | 碎片想法先丢这里 |
| 1-项目 | 正在做的事 |
| 2-领域 | 长期关注的方向 |
| 3-资源 | 知识卡片 + 工具收藏 |
| 4-归档 | 做完的旧项目 |
| 5-模板 | 笔记模板 |
